Settings

Accounts, AI, appearance and users

Accounts

Bank and card accounts your statements are imported into.

Maintenance

Housekeeping for data that was imported before a normalizer improvement.
Re-detect merchant names
Recomputes merchant names for every transaction using the current rules (strips cardholder names, processor codes and store numbers). Rules and remembered merchants follow the new names.
Learn from history
Rebuilds merchant memory from every transaction you have categorized so far, so the next import recognizes them. Runs automatically as you categorize; use this after bulk changes.

AI assistance

Optional. With an OpenRouter key, iSpend can suggest categories for unknown charges and write monthly insights. Suggestions are never applied without your confirmation. Settings are per user.

Appearance

Theme, density and display currency are saved to this browser and to your profile.

Users

Each user has their own accounts, transactions, categories and rules.
